# Data Science & Algorithmic Analysis Portfolio

*Disclaimer: This repository serves as a curated, sanitized portfolio of my work developed over 6 years of self-directed quantitative analysis. All proprietary trading logic and sensitive financial data have been removed to respect my personal intellectual property, while preserving the core analytical frameworks.*

**What you'll find here:**

- **`data_cleaning_pipeline.py`** - A robust time-series sanitization script handling missing values and outliers.
- **`backtest_framework.py`** - A simplified walk-forward backtesting engine with performance metrics.
- **`performance_dashboard.py`** - A Matplotlib/Seaborn visualization dashboard for tracking key KPIs over time.

**Technologies used:** Python (Pandas, NumPy, Matplotlib), Git.
